# 改动说明（v2.1 → v2.2.0 通用化改造）

本文说明这一版**改了什么、为什么改、怎么验证的**，便于审阅与回退。

改造目标：以已发布的 v2.1 为基线，产出一个**不绑定具体机型**的版本——风扇数量自动适配、
数据源逐级降级，同时**保持本机专机版（`hwpanel.py` 2.2.0）已演进的界面与功能不变**。

## 一、总体策略

专机版 `hwpanel.py` 在本机已迭代出频率上限、版本更新、提示条等能力，v2.1 基线则多了
LHM 通用后端。两者各有对方没有的东西，因此本版以**专机版为骨架**，把 v2.1 的通用能力
移植进来，而不是反过来在旧基线上重加功能——这样界面与交互零回归。

| 能力 | v2.1（GitHub 旧版） | 专机版 hwpanel.py | **本版 v2.2.0** |
| --- | :-: | :-: | :-: |
| AWCC 温度 / 风扇 | ✓ | ✓ | ✓ |
| LHM + PawnIO 通用后端 | ✓ | — | ✓ |
| 风扇数量自动探测 | — | — | ✓ **新增** |
| 面板高度随风扇数伸缩 | — | — | ✓ **新增** |

| 更新源设置 / 自动检查开关 | — | ✓ | ✓ |
| 温度平滑开关 | ✓ | ✓ | ✓ |
| 深色卡片界面 / 迷你模式 | ✓ | ✓ | ✓（采用专机版排版） |
| 提示条（toast）/ 关于 / 原地重启 | — | ✓ | ✓ |

## 二、风扇通用化（核心改动）

### 1. `AwccSource`：从固定 ID 表改为探测发现

改造前：

```python
FAN_IDS = (0x32, 0x33)
...
for i, fid in enumerate(self.FAN_IDS):
    rpm = self._ti(self.OP_RPM, fid)
    d["fan%d" % (i + 1)] = rpm if 0 <= rpm < 20000 else None
```

改造后：

```python
FAN_ID_RANGE = range(0x30, 0x40)
FALLBACK_FAN_IDS = (0x32, 0x33)
SENTINEL = 0xFFFFFFFF

def _discover_fans(self):
    found = []
    for fid in self.FAN_ID_RANGE:
        if self._ti(self.OP_RPM, fid) == self.SENTINEL:
            continue
        found.append(fid)
    if not found or len(found) > MAX_FANS:
        return list(self.FALLBACK_FAN_IDS)
    return found
```

`read()` 改为输出统一的 `d["fans"] = [rpm, ...]` 列表，不再用 `fan1` / `fan2` 键。

**为什么能用哨兵值判定**（本机 Dell G3 3590 实测，`_fanprobe.py` 输出）：

| 探测方式 | 无效 ID 的返回 | 能否用于发现 |
| --- | --- | --- |
| `0x05` 读转速 | 恒为 `0xFFFFFFFF` | **可以**（有效 ID 返回真实值，停转返回 `0`） |
| `0x03` 枚举 | 任何参数都返回 `0x32` | 不可以 |
| `0x06` 百分比 | 恒为 `0xFFFFFFFF` | 不可以 |
| `0x09` 最大值 | 对无效 ID 也返回 `5600` | 不可以（只能用来取上限） |

两条保守回退，避免在非戴尔机器上“编造”风扇：

- 一路都没探到 → 退回 `0x32` / `0x33`，让面板至少显示两行 `--`；
- 探到的超过 `MAX_FANS`（6）→ 几乎可以肯定是固件对所有 ID 都返回 `0`，同样退回。

### 2. `LhmSource` 风扇：输出列表并截断

```python
picked.append(rpm)
if len(picked) >= MAX_FANS:
    break
...
d["fans"] = picked      # 原来是 d["fan1"] / d["fan2"]
```

保留原有“未接线空口恒为 0 不计入”的过滤逻辑（`_fan_seen`）。

### 3. `Panel`：动态行数 + 高度伸缩

新增布局函数，把纵向坐标全部从常量改为按路数计算：

```python
def _layout(self, n):
    n = max(1, min(MAX_FANS, int(n or 1)))
    fan_bot = self.FAN_TOP + self.FAN_HEAD + n * self.FAN_ROW
    sys_top = fan_bot + 6
    sys_bot = sys_top + 56
    label_y = sys_bot + 10
    return {..., "fan_rows": [fan_bot - 10 - (n-1-i) * 16 for i in range(n)], ...}
```

- 行文字**自卡片底边向上排**，保证卡片底部留白固定；
- 编译期数值已验算：`n=2` 时风扇卡 `210–268`、系统卡 `274–330`、趋势区 `348–368`、
  总高 `376`，与原固定布局**逐像素一致**；
- 采到数据后若路数变化，`_relayout()` 重建画布并重设窗口高度（保持左上角位置）；
- `_save_cfg()` 记住 `fan_n`，下次启动先按上次路数排版，避免开面板时闪一下。

| 风扇数 | 1 | 2 | 3 | 4 | 6 |
| :-: | :-: | :-: | :-: | :-: | :-: |
| 卡片高度 | 42 | 58 | 74 | 90 | 122 |
| 完整模式总高 | 360 | 376 | 392 | 408 | 440 |

### 4. 其它随动改动

- `Sampler._merge_lhm()`、`_update_status()`、`_apply()` 全部改用 `fans` 列表；
- 迷你模式：1 路 `风扇 1700 转/分`、2 路 `风扇 1700 / 1960`、3 路以上
  `风扇 3 个 · 最高 2220`，避免单行溢出；
- 风扇进度条归一化基准：有标称上限用上限，否则用本次运行观察到的峰值（`fan_scale`）。

## 三、顺手修掉的两个真实缺陷

### 1. 首屏要等近 10 秒才出数

改造前，硬盘温度查询在同一轮里**发布之前**执行；没有 LHM 的机器只能走 PowerShell
`Get-StorageReliabilityCounter`（实测 0.5–6 秒），于是首屏一直停在 `--`。

改为先发布本轮结果、再单独补一轮硬盘温度：

```python
self._update_status(d)
self._store(d)                     # 先出数
if not lhm.get("disks") and now - self._last_disk >= 45.0:
    rows = self._disk.read()
    self._last_disk = now
    if rows:
        self._store({"disks": rows})   # 慢源单独补
```

实测首屏出数时间：**≈10s → 0.71s**。

### 2. 刷新定时器重复挂载

菜单“立即刷新”、切迷你模式、改频率上限都会带 `force` 调 `_tick()`，原实现每次都再挂一条
`after` 链，点几次刷新就越来越快。改为保存句柄、先撤后排，`quit()` 里也撤。

## 四、刻意保持不变的部分

- 只读定位：不写风扇转速、不切散热档位、退出不复位硬件；
- 界面配色、卡片分区、字体、进度条坐标（含 `IX+82 / IR-6`、`IR-96`、`IR-132` 等右移修正）；
- 交互：左键拖动、双击切迷你、右键菜单层级、`Esc` 退出、单实例前置；
- 温度平滑（4 点滑动平均）与开关语义；
- CPU 频率上限的实现（`powercfg` AC+DC 双写 + 回读校验 + 不依赖语言关键词解析）；
- 版本更新的三道校验与 `.bak` 备份策略。

只做了品牌对齐：程序名 `TempPeek`、配置 `~/.tempeek.json`、互斥量
`TempPeek_SingleInstance_v1`、更新文件名 `tempeek.py`。

## 六、回退方法

改动集中在 `tempeek.py` 一个文件，按下面三处即可退回“固定双风扇”：

1. `AwccSource._discover_fans()` 直接 `return [0x32, 0x33]`；
2. `Panel.__init__` 里 `self.L = self._layout(2)`；
3. `_apply()` 里删掉 `len(fans) != self.L["n"] → _relayout` 这一段。

此时行为等同 v2.1 + 专机版功能，只是不再适配单风扇 / 多风扇机型。
