硬件监控面板 v2.1 —— Windows 桌面硬件监控悬浮面板

一、功能
  实时显示处理器温度 / 频率 / 占用、显卡温度 / 占用 / 显存、主板与硬盘温度、
  风扇转速、内存、网络与磁盘读写，并绘制处理器温度趋势。
  左键拖动 · 双击切换迷你模式 · 右键菜单（刷新间隔 / 透明度 / 置顶 / 退出）· Esc 退出

二、安装
  1. 双击“硬件监控面板_安装包_v2.1.exe”。
  2. 安装程序会安装到 C:\Program Files\HWPanel，并创建桌面与开始菜单快捷方式。
  3. 默认勾选“安装 PawnIO 传感器驱动”，用于读取 CPU 温度与风扇转速。
     不需要时可取消勾选；驱动也可以在“设置 → 应用”里单独卸载。
  4. 安装包未购买商业代码签名，若 SmartScreen 提示“未知发布者”，
     点击“更多信息 → 仍要运行”即可。
  5. 安装完成后启动面板；Windows 会请求管理员权限（读取传感器需要）。

三、数据来源
  处理器温度 / 风扇 / 主板 / 硬盘   LibreHardwareMonitor + PawnIO
  戴尔机型温度 / 风扇              AWCC WMI（存在时优先）
  显卡温度 / 占用 / 显存           nvidia-smi；无 NVIDIA 驱动时温度回退到 LHM
  处理器频率 / 内存 / 网络 / 磁盘   psutil 与 Windows 性能计数器

四、系统要求
  Windows 10 / 11 64 位；管理员权限。
  PawnIO 为签名内核驱动；未安装时 CPU 温度与风扇转速显示“--”，
  状态栏提示“部分数据不可用”。
  核显机器没有独立显卡温度、无风扇设备没有转速读数，均属正常现象。

五、常见问题
  1) 状态显示“部分数据不可用”
     多为未安装 PawnIO 或拒绝了管理员权限。重新运行安装包勾选驱动，
     或以管理员身份启动面板。
  2) 只列出一个风扇
     主板 Super I/O 上未接线的转速输入口恒为 0，面板不会把它们当成额外的风扇显示；
     因此看到几个风扇，就是几个真正在转的风扇。真风扇停转时仍显示 0 转/分
     （只要本次运行中转起来过就会保留那一行）。
  3) 显卡占用 / 显存显示“--”
     这两项来自 NVIDIA 驱动自带的 nvidia-smi；AMD / Intel 显卡只能显示温度。
  4) 面板启动两次只有一个窗口
     正常。面板为单实例，第二次启动会把已有窗口提到前台。
  5) 配置保存在哪里
     %USERPROFILE%\.hwpanel.json（位置、透明度、迷你模式等）。
  6) 升级安装时提示面板正在运行
     先在面板右键菜单选择“退出”，再运行新安装包。

六、卸载
  设置 → 应用 → 硬件监控面板 → 卸载；
  若要移除传感器驱动，再卸载“PawnIO”。
  配置文件不会自动删除，可按需手动删除 %USERPROFILE%\.hwpanel.json。

七、便携使用
  复制安装目录（C:\Program Files\HWPanel）到其他位置，直接运行 HWPanel.exe 即可，
  无需再次安装；传感器驱动仍需另行安装。

本程序只读取硬件数据，不修改风扇、电压或任何硬件设置，不联网上传数据。
