TempPeek v2.2.0 —— Windows 桌面硬件监控悬浮面板

一、功能
  实时显示处理器温度 / 频率 / 占用、显卡温度 / 占用 / 显存、主板与硬盘温度、
  风扇转速、内存、网络与磁盘读写，并绘制处理器温度趋势。
  风扇数量自动识别（1～6 路），面板高度随实际路数伸缩，不预留空行。
  左键拖动 · 双击切换迷你模式 · 右键菜单（迷你模式 / 刷新间隔 / 透明度 / 置顶 /
  温度平滑 / CPU 频率上限 / 检查更新 / 关于 / 退出）· Esc 退出

二、安装
  1. 双击“TempPeek-Setup-v2.2.0.exe”。
  2. 安装程序会安装到 C:\Program Files\TempPeek，并创建桌面与开始菜单快捷方式。
  3. 默认勾选“安装 PawnIO 传感器驱动”，用于读取 CPU 温度与风扇转速。
     不需要时可取消勾选；驱动也可以在“设置 → 应用”里单独卸载。
  4. 安装包未购买商业代码签名，若 SmartScreen 提示“未知发布者”，
     点击“更多信息 → 仍要运行”即可。
  5. 安装完成后启动面板；Windows 会请求管理员权限（读取传感器需要）。

三、数据来源
  处理器温度 / 风扇 / 主板 / 硬盘   LibreHardwareMonitor + PawnIO
  戴尔机型温度 / 风扇              AWCC WMI（存在时优先，风扇路数自动探测）
  显卡温度 / 占用 / 显存           nvidia-smi；无 NVIDIA 驱动时温度回退到 LHM
  处理器频率 / 内存 / 网络 / 磁盘   psutil 与 Windows 性能计数器

四、系统要求
  Windows 10 / 11 64 位；管理员权限。
  PawnIO 为签名内核驱动；未安装时 CPU 温度与风扇转速显示“--”，
  状态栏提示“部分数据不可用”。
  核显机器没有独立显卡温度、无风扇设备没有转速读数，均属正常现象。

五、常见问题
  1) 状态显示“部分数据不可用”
     多为未安装 PawnIO 或拒绝了管理员权限。重新运行安装包勾选驱动，
     或以管理员身份启动面板。
  2) 风扇数量与机器不符
     面板按传感器接口自动探测：接口存在但风扇未接线时仍会显示该行（0 转/分），
     属正常现象；只有接口完全不存在时才不显示。
  3) 显卡占用 / 显存显示“--”
     这两项来自 NVIDIA 驱动自带的 nvidia-smi；AMD / Intel 显卡只能显示温度。
  4) 面板启动两次只有一个窗口
     正常。面板为单实例，第二次启动会把已有窗口提到前台。
  5) 配置保存在哪里
     %USERPROFILE%\.tempeek.json（位置、透明度、迷你模式、频率上限等）。
  6) 升级安装时提示面板正在运行
     先在面板右键菜单选择“退出”，再运行新安装包。
  7) CPU 频率上限怎么恢复
     右键菜单 → CPU 频率上限 → 100%。该设置写入 Windows 电源计划的
     最大处理器状态，重启后仍生效，随时可改回。

六、卸载
  设置 → 应用 → TempPeek → 卸载；
  若要移除传感器驱动，再卸载“PawnIO”。
  配置文件不会自动删除，可按需手动删除 %USERPROFILE%\.tempeek.json。
  若曾设置 CPU 频率上限，建议先恢复 100% 再卸载。

七、便携使用
  复制安装目录（C:\Program Files\TempPeek）到其他位置，直接运行 TempPeek.exe 即可，
  无需再次安装；传感器驱动仍需另行安装。

本程序只读取硬件数据，不修改风扇转速、电压或 BIOS。
仅当用户在菜单中主动设置“CPU 频率上限”时，才写入 Windows 电源计划的最大处理器状态。
仅在用户开启“检查更新”时访问 GitHub 读取版本号，不上传任何本机数据。
